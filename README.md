# Number-Guessing-Game

## Description
A Python based number guessing game where the user guesses a randomly generated number with feedback for each attempt.

## Objectives
- Generate a random number using Python
- Allow multiple attempts
- Provide feedback for each guess
- End the game on correct guess or when attempts are exhausted

## Technologies Used
- Python
- random module

## How to Run
```bash
python number-guessing-game.py
